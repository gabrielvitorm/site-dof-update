# Prompt — Implementação

Leia todo o diretório `.context/` na ordem definida em `.context/README.md` e também `AGENTS.md` se existir.

Objetivo: implementar a próxima tarefa do plano do projeto sem alterar decisões já aprovadas.

Regras:
1. trate `.context/RULES.md` e `.context/DECISIONS.md` como restrições obrigatórias;
2. não invente conteúdo faltante — preserve placeholders;
3. siga TDD para regras de negócio e integrações;
4. faça mudanças pequenas e revisáveis;
5. valide mobile, acessibilidade e performance;
6. não exponha segredos no frontend;
7. não mude o checkout para solução própria;
8. execute testes antes de concluir;
9. atualize documentação/contexto somente se uma decisão realmente mudar;
10. reporte arquivos alterados, testes executados e riscos pendentes.
